# Toolbar

[Indeks](README.md)

Toolbar berada di bagian atas template. Kelompok pertama berisi pemilih **Tahun** dan tombol **Impor**. Kelompok aksi berisi **Perbarui** dan **Cetak**. Pada layar kecil, kelompok tombol dapat turun ke baris berikutnya.

| Elemen | Kelas pada contoh |
| --- | --- |
| Kelompok tahun dan impor | ur-toolbar |
| Pemilih tahun | ur-toolbar-period dengan Select2 |
| Tombol Impor | btn btn-sm ur-toolbar-import |
| Kelompok aksi | module-toolbar-actions |
| Tombol Perbarui dan Cetak | btn btn-sm btn-light-primary ur-button |

Pada demo, pemilih tahun dan tombol Perbarui menerapkan filter. Cetak membuka dialog cetak ringkasan, dan Impor membuka modal informasi. Tombol modul memakai tindakan yang tersedia pada halaman tersebut.
