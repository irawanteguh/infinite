# REST API — Collections, Environment, ClaimGuard

- [Collection](../../../app/Modules/RestAPI/Controllers/Collection.php) dan [Environment](../../../app/Modules/RestAPI/Controllers/Environment.php) merender `restapi/collection` dan `restapi/environment`. Keduanya memakai [WorkspaceStorage::storage()](../../../app/Modules/RestAPI/Libraries/WorkspaceStorage.php) untuk penyimpanan JSON berbasis file di `restapi-data`. Scope utama memakai group/org dan jalur kompatibilitas mengenali scope lama yang juga memakai user. Trait memeriksa sesi. Workspace dipakai oleh [SATUSEHAT](satusehat.md).
- `Collection::send()` adalah eksekutor request server-side dengan pemeriksaan di controller. Lihat [integrasi](../integrations.md) untuk transport dan timeout. UI ada di [Views](../../../app/Modules/RestAPI/Views/) dan [aset REST API](../../../public/assets/js/restapi/), terutama `storage.js`, `collection.js`, dan `environment.js`.
- [Claimguard::evaluate()](../../../app/Modules/RestAPI/Controllers/Claimguard.php) membaca JSON diagnosis, prosedur, dan konteks, menjalankan algoritma internal, lalu memberi hasil evaluasi. Route `api/v1/claimguard` juga mengekspos template, preset, request body, dan ekspor koleksi. Ini merupakan aturan aplikasi. Rujuk controller saat mengubah kriteria.

Workspace web mengikuti login/grant. Prefix `api/*` dikecualikan dari auth global. Tidak ditemukan model database modul untuk alur di atas. [Routing](../routing.md) mencatat fallback dispatcher yang belum ditemukan. Eksposur API di infrastruktur serta isi workspace deployment belum diperiksa.
